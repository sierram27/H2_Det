# H2_Det
H2 Detonation exploration

requirements.txt in the H2_det folder includes a requirements.txt for a virtual environment setup. 

Additional package sdtoolbox available here under H2_det needs to be added to the virtual environment manually. (Location: H2_det/.venv/lib/python3.14/site-packages)
  The mechanism used in main.py is not natively inside of sdtoolbox. It is in the sdtoolbox in this repository.
  SDToolbox documentation and original download can be found here: https://shepherd.caltech.edu/EDL/PublicResources/sdt/nb/sdt_intro.slides.html
